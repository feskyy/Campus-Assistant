# Campus Assistant

Мобильное приложение на Flutter для студентов: расписание, новости и события кампуса, карта аудиторий.
Индивидуальный проект по дисциплине Flutter, тема №2.

## Цель
Дать студенту в одном приложении ближайшие занятия с аудиторией, новости и события университета и карту корпусов, при этом расписание должно открываться без интернета.

## Целевая аудитория
- студенты, которым нужно быстро узнать, где и когда следующая пара;
- первокурсники и гости кампуса, которые ищут аудиторию или мероприятие.

## Экраны (план)
1. Вход и регистрация
2. Главная
3. Расписание (и детали занятия)
4. Новости и события (и детали)
5. Карта кампуса
6. Профиль и настройки

## MVP (черновик)
Расписание по группе, лента новостей и событий, избранное, карта корпусов и аудиторий, тёмная тема, офлайн-режим, push-уведомления.

## Технологии (план)
Flutter/Dart, Riverpod, GoRouter, REST + JSON, SQLite/Hive, SharedPreferences, Firebase (Auth, Firestore, FCM, Crashlytics), Google Maps, Kotlin MethodChannel.

## Статус по неделям

| Неделя | Подтверждённое состояние |
|---|---|
| 1 | Flutter/Dart SDK и учебные задачи присутствуют; учебная защита не проверена |
| 2 | Экраны и компоненты Material 3 присутствуют; добавлены проверки небольших экранов |
| 3 | Модели и настройки есть; состояние приложения управляется Riverpod, пакет Provider пока не используется |
| 4 | Общий Riverpod-источник, интерфейс репозитория и JSON-модели; полное соответствие учебной архитектуре требует отдельной оценки |
| 5 | Собственный HTTP REST backend с явно демонстрационными данными; университетский API отсутствует |
| 6 | SharedPreferences: тема, группа, избранное и офлайн-кэш; сохранение покрыто тестами |
| 7 | GoRouter, вкладки, подробности, возврат и отдельный демо-режим; навигация покрыта widget-тестами |
| 8 | Firebase SDK и правила подготовлены; настоящая авторизация, Google, Firestore и доставка FCM не проверены без проекта |

## Текущее поведение

По умолчанию приложение использует явно обозначенные локальные демонстрационные данные.
Фиктивная авторизация удалена. Без Firebase доступен отдельный гостевой демо-режим.
Расписание: выбор дня/группы, сортировка, текущее занятие и подробности.
Лента: поиск с debounce, категории, новости/события, избранное и подробности.
Каталог корпусов/аудиторий: поиск и подробности; Google Maps отложен до недели 9.
Тема, группа, избранное и REST-кэш сохраняются локально.
